## 📌 Sobre o projeto

Site one-page criado do zero. O objetivo é transformar visitantes em potenciais clientes, passar profissionalismo e facilitar a contratação dos meus serviços de criação de sites e landing pages.

## ✨ Funcionalidades

- Layout **responsivo** (celular, tablet e computador)
- Menu de navegação com versão **mobile**
- Rolagem suave entre as seções
- Animações discretas ao entrar na tela
- Botões de orçamento integrados ao **WhatsApp**
- Formulário de contato com **validação** dos campos
- Logo com efeito **3D** que acompanha o mouse
- SEO básico e boas práticas de acessibilidade

## 🧩 Seções

Início · Sobre · Serviços · Portfólio · Como funciona · Depoimentos · Contato · Instagram · Rodapé

## 🛠️ Tecnologias

- **HTML5**: estrutura semântica
- **CSS3**: variáveis, grid, flexbox e animações
- **JavaScript**: menu, validação do formulário e interações
